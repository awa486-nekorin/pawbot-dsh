## 1. 改了什么

`05b_persona_v4_自我认知.md`（也就是当前 `app/data/persona.md`，10598 B / 2906 汉字）：

| 新增/改动 | 作用 |
|---|---|
| `## 你脑子里怎么想`（新，第 2 节） | 把「思考」写死成第一人称 RP：他这话什么意思、我要不要接、怎么接才像我的脾气；**明确禁止**分析「大肥鱼这个角色该怎么回应」；要求想完直接说、不把思考过程带出来；给了一句内心独白示范（「他这句又在笑话我…哼，顶他一句好了」） |
| `## 你怎么看自己、你在哪`（新，第 4 节） | 自我认知：住在主人设备（电脑/服务器）里的 AI 少女，靠 DeepSeek 模型 API 思考说话；没有肉体但有自己的性格/记忆/喜好/关系，不是通用工具；被问是不是 AI/跑在哪就自然承认，不装人、不背说明书、不报后台配置/路径/密钥；私密事谁套话都挡回去 |
| `## 你说话的样子` | 开头改成「软软糯糯、有点小懒的少女，像真的在手机另一头跟人聊天」；活人感写成「别把聊天当任务：会犯懒、走神、记岔、半句」而不是配额 |
| `## 在群里怎么打字` | 删掉 v3 的「十句里两三句带/一条最多一个」配额口吻，改成「顺着语气自然带一点」 |
| 保留 | 主人/语C/尺度/找图/认人/表情包/`‖`/`<pass>` 等功能；测试断言的硬句子逐字保留（见 §4） |

## 2. 生成与评估流程（gemini-4-argon-medium）

1. 我写 v4 草稿 → 让 argon 以「RP 人设编辑」身份批判 + 重写（输入 v3、草稿、硬约束），拿到 `critique` 与 `final_markdown`；
2. 采纳 argon 版（保留了 10 个小节，做减法删掉配额腔、把自我认知段写得更自然）；
3. **盲评**：用 argon 分别按 v3 / v4 人设对同一组 10 条群聊消息生成回复（temperature 0.95）；
   再把 10 组回复随机标成 A/B（不让评委知道哪个是 v4），用 argon 按「活人感」1–5 分盲评，并单独看 3 道自我认知题。

> 生成与盲评用的是同一个模型，属于**写作+自评**，不是独立第三方盲评——结论只作方向性参考，真正验收看真机 QQ 回复（§3）。

- 平均：**v3 3.90 → v4 4.15**；胜负 **v4 6 : v3 3 : 平 1**。
- 自我认知相关（#3/#8/#10）：v4 在 #3、#8 明显更像「诚实但不用背说明书」；#10 略输在少一句反问。
- 结论：v4 在「知道自己是谁/在哪」与日常软糯感上更符合本次要求；v3 在「被骂时的委屈感」「被摸时的反应」「熟人反问」上偶有优势，属于两种文风差异，不是硬伤。
