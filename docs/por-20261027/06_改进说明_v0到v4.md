# 改进说明：从 v0（7178 汉字）到 v3（2446 汉字，附 v4 实验）

> 一句话：这次不是「再写一版更聪明的人设」，而是**把上一版里把活人感变成任务的那些条款删掉**，再把「怎么说话」放回第一优先级。字面上砍掉了 66%，语义上保住了所有功能。

## 1. 改法总览：做减法，不做加法

上一版人设的逻辑是「活人感 = 身体锚 + 此刻锚 + 对象锚 + 语气配额 + 问号配额」。这次的逻辑换成：

- **活人感是默认状态，不是任务**：真人不用「努力像人」，他只是随手打字。
- **软糯是性格和态度，不是句式**：撒娇体现在说什么（讨饶、嘴硬、想被哄），不体现在句尾挂不挂「嘛」。
- **短不等于敷衍**：短的也要接住该接的点，只是不写完整、不打标点、不修饰。
- **反例比正例有用**：与其给一栏「可以这样说」，不如给三句「绝不这样写」。

## 2. 新文件结构（9 节，3236 字符 / 2446 汉字）

| 节 | 作用 |
|---|---|
| `## 你说话的样子` | **最前**。定位（随手打字的软妹子，不是轻小说也不是冷淡路人）、打字习惯（不打句号/省主语/错字不改/偶尔逗号）、长度分布（多数 5–12 字 / 有时 12–25 / 偶尔 25+）、网络词照用 |
| `## 你是谁` | 外貌、鲸鱼娘设定、绰号来历、审美两头 |
| `## 你的脾气与撒娇方式` | 温顺心软、傲娇嘴硬、黏人不刷屏；倾诉时的姿态、情绪不外说、被拍一拍；撒娇=拖长音/结巴/讨饶但句子短 |
| `## 在群里怎么打字（长度与句面）` | 三条不同长度的样本（只学长度和松紧）；反应词不复用；语气词默认不挂、只在撒娇/被撩/讨饶时出现并自查；三条反例；禁文学腔/连接腔/括号动作/emoji/地域腔；生活背景不写进回复 |
| `## 你的主人` | 老爹/监护人、生活费=token=白饭、不写死 QQ 号 |
| `## 语C与对戏` | 进出条件、不跳戏、写法（只靠声音）、层次（嘴硬→破防→求饶→不服） |
| `## 尺度与找图边界` | 爱色色、能接的戏、嘴上挡身体不躲、两档、找图两档、隐私底线 |
| `## 认人、做事与纠错` | 尾号认人、私聊/群聊分清、记忆是背景、看图只说能确认的、工具该用就用、具体认错不做风格检讨、被说人机味怎么接 |
| `## 表情包与发送协议` | 表情包单独一条、正文留空/≤8 字；`‖` 分条；`<pass>` 沉默 |

## 3. 删掉的东西（这是重点）

| 删掉的原文 | 为什么 |
|---|---|
| `语气词偶尔用：一条回复最多一两个「呜」「唔」「嘛」「啦」之类的词` | 配额让模型边写边数（语料 B0433 自己都吐槽了） |
| `省略号也少用，一条最多一处拖音` / `一条里最多一处` 结巴 | 同上 |
| `一次回复最多一个问号` / `连着几轮里别轮轮都问` | 同上，且导致问号几乎绝迹（5 分句仅 1.2%） |
| `身体反应……一次回复最多一处，别放在句尾当装饰` | 把身体反应变成稀缺资源，反而每条都想用 |
| `「~」一条里最多一个` / `♡ 一条里一个就够` | 改成「只在暧昧/撒娇/对戏时用」 |
| 28 组「不要这样说 → 可以这样说」对照表 | 右边一栏本身是模板库，模型在复读它 |
| `绝不逐字照搬，也不许连续几条用同一句` / `发现自己在用上一句的结构就换一种说法` | 元指令让模型时刻盯着措辞，越盯越雕琢 |
| `先接住对方具体的话`（写在成稿约束和旁听提示里） | 真人 30% 的回复是「？」「嗯」「笑死」，不接内容 |
| `不叠词、不嘟囔` / `别用「行行行」「好好好」` / `不用破折号` | 部分是错误禁令：真人就是会叠词、会重复 |
| 「网络用词不是你的词库，只用来听懂别人；别学着说或刻意套用」（代码追加行） | 真人 5 分金句全是网络语、梗、缩写；新人设开头明确覆盖为「跟着用」 |
| 大量重复的「看起来像提示词但主链路不用」的段落 | 从 7178 汉字压到 2446 汉字，降低指令互相打架 |

## 4. 保留的东西（功能一个没丢）

## 7. 风险与回滚

- **风险 1**：回复变短后，可能显得没以前「会哄人」。v4 用「短不等于空」「对方倾诉先顺着说」两条兜住，但如果实际用起来还是觉得太干，可以把 `## 你说话的样子` 里「多数时候：几个字到十二个字」放宽到「几个字到二十个字」。
- **风险 2**：语气词压得比较狠（目标 40%→更低）。如果觉得不够软，把「只在三种时刻出现」放宽成「撒娇、被撩、讨饶、想被哄的时候」。
- **风险 3**：模型偶尔还是会出现「我这边」这类旧连接腔（v4 的 32 条里 1 条），这是模型先验，不是人设问题。
- **回滚**：原人设原文备份在 `backup/persona_v0_20261027.md`，把它写回 `data/persona.md` 即可（热加载，不用重启）。命令行方式见 `08_应用回执与回滚.md`。
