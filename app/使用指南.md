# PawBot 使用指南：登錄、接入、日常使用

> 架构一句话：QQ ⇄ NapCatQQ（协议端） ⇄ 反向 WebSocket `ws://127.0.0.1:6199/ws` ⇄ PawBot ⇄ DeepSeek。
> NapCat 的 `config/onebot11.json` 里填好这条连接（array 格式、无 token），**接入环节不需要改任何东西**，两边都启动就会自动连上。

---

## 一、你要做的三步

### 1. 启动 PawBot

装好 DSH 插件后它会自动拉起 PawBot；也可以手动在 `app/` 目录跑 `python run.py`。

看到这两行就是成功：

```
[INFO ] OneBot 反向 WebSocket 已监听 ws://0.0.0.0:6199/ws
[INFO ] WebUI 已启动 http://127.0.0.1:6185
```

浏览器打开 <http://127.0.0.1:6185> 可以看状态、日志、配置。

### 2. 登录 QQ（NapCat）

双击 NapCat 安装目录下的 `launcher.bat`（Win10 用 `launcher-win10.bat`）：

- 以前登录过的账号可以直接选号快速登录（账号列表由 NapCat 自己维护）；
- 新账号按提示扫码。`quickLoginExample.bat` 是快速登录写法的例子。

登录成功后 NapCat 会自动连 PawBot（配置已启用）。**这个窗口要一直开着。**

### 3. 验证连接

- WebUI <http://127.0.0.1:6185> 状态页：`connections` 出现 1 个账号即连上；
- 或 PawBot 日志出现 `协议端已连接 ... self_id=你的QQ号`；
- 群里 `@机器人` 或叫「大肥鱼」说一句话，看它回不回。

## 二、群里怎么用

**看群与参与**：普通群消息都会进入 AI 的上下文与参与判断，不需要先 @、点名或拍一拍。大肥鱼有兴趣、有具体内容可接才加入，否则选择内部 `<pass>` 保持沉默（这个标记不会发到 QQ，也不写成自己的回复）。@ 或叫名字表示直接找它，但不是旁听的必要条件。自己的消息和指令不进入这个判断；私聊正常回复。`chat.reply_mode=never` 可以关闭群 AI 聊天，其他模式均参与旁听。每条普通群消息会产生模型请求，繁忙群可能排队，模型失败时保持沉默。

**回复分条**：模型一次写完整段回复，在要另起一条的位置留 `‖` 记号；每条通常一两句。发送层只按 `‖` 拆成独立 QQ 消息，每条发送前按该条字数模拟打字（约 5.5 字/秒，0.9–6 秒封顶），后续条目另加 1.4–2.8 秒段间停顿；标记本身不显示；没有标记就保持一条，不再按字数切断。每次最多三条（同时受 burst 配置约束），超出的内容合并进最后一条。图片保留在原先的内容顺序中；引用和 @ 只放在第一条。代码里的 `||` 原样保留。

**Pixiv**：运行 `/pixiv登录` 会启动专用 Chrome（独立资料目录，不读取日常浏览器），并打开 Pixiv 页面。请在该窗口登录 Pixiv，并让它保持运行；然后运行 `/pixiv登录 状态`，确认显示专用 Chrome、Pixiv 页面与登录状态。搜索通过该会话后台调用 Pixiv 搜索 API。非会员账号的「按热门排序」会被 Pixiv 忽略，所以改用收藏标签分层：先搜 `10000users入り`，不够再降到 `5000users入り`、`1000users入り`（`tools.pixiv_popular`，默认 `10000,5000,1000`）。漫画、动图和 Pixiv 标记为 AI 生成的作品会直接跳过（`tools.pixiv_exclude_ai`），短边低于 1000px、收藏低于 500 的也不要；剩下的按收藏数和收藏率（收藏/浏览）排序，并在前列里随机挑，避免每次都是同几张。发图用完整原图：3MB 以内直接内联，更大的原图存到 `data/image_cache/`（只留最近 60 张）交给同机的 NapCat 读取，不再退回 Pixiv 压缩过的 1200px 版本。搜索本身不算浏览；真正发出去的作品会在专用 Chrome 的后台分页里打开约 8 秒再关闭，这样 Pixiv 账号会留下浏览记录（`tools.pixiv_record_view` 可关闭）。若窗口未运行、不是专用实例或登录状态未确认，`/pixiv登录 状态` 会报告原因，登录态搜索不会悄悄退成匿名结果。

**Pixiv 標籤搜索**：大肥鱼会按当前主题现场组合内容标签，保留主题与角色；收藏门槛与图片尺寸作为单独的质量筛选条件。查询里出现未成年相关词时只把搜索降级成 SFW 继续找，不会直接拒绝；明显福瑞标签会被过滤；普通猫耳、狐耳关键词不自动算福瑞。图片取不到完整文件时不发送损坏截断图，并会尝试合格的下一个作品。
**指令**（前綴 `/` 或 `!`，也允许无前缀直接说；群里输 `help` 可看全列表）：

| 指令 | 作用 |
|---|---|
| `ping` / `在吗` | 探活，回 pong·延迟·在线状态 |
| `help` / `帮助` | 列出全部指令 |
| `状态` | 收发统计、处理器数 |
| `echo` / `复读` <内容> | 原样复述 |
| `记住` <内容> | 写入长期记忆 |
| `清空` / `重置` | 忘掉当前会话（聊天+话题一起清） |
| `撤回` | 撤回自己上一条 |
| `pixiv登录` | 打开专用 Chrome 绑定 Pixiv |
| `荤` / `荤 1` / `当前尺度` | 群内尺度档位（1收敛点/2爱色色；**没有素聊档**） |
**回复节奏**：收到消息会先等一小会儿（默认 1.6 秒，最多 4.5 秒），对方在这段时间里接着发的话会合在一起看，只回最后那条；生成期间继续发来的消息会并入下一轮，不会被丢掉。

**群友档案与好感**：每个说过话的人在 `data/people/<QQ号>.md` 有一份档案，记名字、性格、说话方式、在意什么，外加 0–100 的「好感」。被夸、被道谢会慢慢涨，被骂掉得更快，14 天不互动回落一半；白名单主人（`account.owner_ids`）默认从 85 起步，其他人从 50 起步。好感只影响语气（亲不亲近、要不要热络），不会说出分数。后台「群友」页可以看每个人当前好感和性格，点「编辑档案」能直接改文件。

**情绪与媒体**：大肥鱼有 8 维情绪（开心、兴奋、好奇、烦躁、低落、亲昵、得意、疲惫，基线 50），被夸会开心得意，被骂会烦躁、回得更短更冲，长时间没互动会慢慢回到 50 附近。情绪只影响语气，不会把分数说出来。图上「来点图」没有指定主题时，默认从 Pixiv 排行榜/主页推荐取前 20 个候选，再用第二个模型给缩略图打美术分，低于 6 分不发；给了标签才按标签搜 Pixiv。图片和表情包永远是单独的一条消息，不会和文字挤在一起；同一个会话里发过的图不会重复发，表情包几轮内最多一张。

**账号修改不用指令**：主人的 QQ 加进 `account.owner_ids` 后，私聊或在群里直接说就行，不需要 `/` 前缀，也不用 @ 机器人。例如：

| 你说 | 效果 |
|---|---|
| `把昵称改成小蓝鱼` / `名字改成小蓝鱼` | 改自己 QQ 昵称 |
| `帮我改签名 游来游去` / `签名改成 游来游去` | 改个性签名 |
| `把头像换成 <https图片地址>` | 改头像；不接受本机路径 |
| `把头像换成这张图`（同时发一张图） | 用这条消息里的图作头像 |
| `把群名片改成 塘主` | 改当前群里自己的群名片 |
| `把群名改成 鱼塘` | 需要机器人是管理员或群主 |
| `给我头衔 塘主` / `给 123456 头衔 塘主` | 需要机器人是群主 |
| `你能改什么` / `账号能力` | 列出支持项 |
| `查看你的资料` / `查看账号能力` | 看自己的昵称、签名 |

只有 `account.owner_ids` 里的人说话才算，别人说同样的话不会执行；否定句（「不要改…」）、问句、引用别人的话、复述历史也不会触发；模型自称「主人已授权」无效。个人标签没有可用接口，做不了；也不会退群、删好友或拉黑。


**给机器人拉进群**：用你自己的 QQ 把机器人账号邀请进群即可（`whitelist.group_ids` 为空 = 不限制任何群）。

## 三、日常改动：哪些不用重启

| 改什么 | 生效方式 |
|---|---|
| 人设 `data/persona.md` | 保存即热加载（按 mtime），下一句话生效 |
| 记忆 `data/memory/{facts,slang,impression}.md` | 热加载 |
| 表情包 `data/stickers/` | 热加载（大肥鱼可用 `save_sticker` 自己收藏，上限 200） |
| 插件 `plugins/*.py` | WebUI 点「重载」，或 `POST /api/plugins/reload` |
| 配置 `data/config.json` | WebUI 配置页改（会写回文件） |

**需要重启的**：`pawbot/` 下的核心代码（`core.py`、`safety.py`、`agent.py`、`persona.py` 等）。在 DSH 面板点「重启 PawBot」（或重跑一次 `python run.py`）即可。

## 四、WebUI（http://127.0.0.1:6185）

状态（连接数/收发/心情）、实时日志（SSE）、配置编辑、插件开关与热重载、会话查看与清空、手动发消息测试。API 也有同样能力（`/api/status`、`/api/logs`、`/api/session/clear` 等）。

## 五、常见坑（都踩过，写在这里防重蹈）

1. **`.bat` 编码**：必须纯 ASCII 或 GBK；UTF-8 + `chcp 65001` 混用会整脚本崩。
2. **本机回环被代理劫持**：`127.0.0.1` 请求需绕开系统代理（代码里已处理，手动 curl 失败时先想这个）。
3. **9222 端口**：被日常浏览器占用时 Pixiv 专用 Chrome 会拒绝启动（打码链路不可用）。
4. **两个窗口都不能关**：NapCat 窗口关了 QQ 就断；PawBot 窗口关了机器人就下线。
5. **不能同时开两个 PawBot**：6199 端口冲突，第二个起不来。
6. **限流是刻意的**：每会话每分钟 12 条、10 秒内最多 3 条，测试太密会被静默丢弃（日志见 `[safety] 触发节流`）。
7. **API key 别提交**：`data/config.json` 里有 `llm.api_key`、`slang.api_key`，已在 .gitignore。
